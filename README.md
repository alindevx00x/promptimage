# PromptImage — Free AI Image Prompt Directory

**Live Website:** [https://promptimage.cc/](https://promptimage.cc/)

A curated, community-driven AI image prompt library featuring **5,200+ tested visual prompts** with high-resolution artwork previews, customizable prompt variables, 1-click copy, and direct model launchers for **GPT Image, Midjourney v6.1, FLUX.1, Nanobanana, and Seedance**.

## Key Features

- **5,200+ Curated AI Prompts**: Browse a continuously updated visual gallery of portraits, graphic design posters, commercial product photography, 3D renders, logos, editorial layouts, and surreal art at [promptimage.cc](https://promptimage.cc/).
